# 鸣潮 · 编队立绘 & 海报立绘 收集

本仓库收集《鸣潮》（Wuthering Waves）所有共鸣者的 **编队立绘** 与 **海报立绘**，尽量使用原图，按角色属性分类管理。

## 目录结构

```
ww-illustrations/
├── {属性}/
│   ├── 编队立绘/
│   │   └── {角色名}.png
│   └── 海报立绘/
│       └── {角色名}.png
└── manifest.json   # 原始抓取数据（含图片 URL）
```

属性分类：导电、冷凝、热熔、气动、衍射、湮灭。

## 数据来源

- 鸣潮 WIKI（库街区）：https://wiki.kurobbs.com/mc/home
- 角色图鉴目录：https://wiki.kurobbs.com/mc/catalogue/list?fid=1099&sid=1105

图片来源于 WIKI 词条中的角色基础资料区域，去除 `?x-oss-process` 参数以获取原图。

## 说明

- 共收集 65 位共鸣者。
- 部分角色（如「莉莉」）仅提供一张立绘，已归入「海报立绘」。
- 漂泊者（多属性版本）按其属性分别归类。
